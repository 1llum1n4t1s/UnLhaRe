# KHC malformed archive fixtures

`fixtures.bundle(input_bytes)` returns a mapping of case names to bytes and a record of byte sizes and SHA-256 hashes. It performs no filesystem access. Input is capped at 16 MiB; the four output byte arrays plus a 64 KiB record allowance are capped at 64 MiB plus 64 KiB. Persisting these bytes for CLI use requires a separate, race-safe no-follow and no-replace file creation implementation; no path-based writing entry point is provided here.

`fixtures.export_verified(input_bytes, expected_sha256, outputs)` links a previously verified input to four caller-owned empty binary streams keyed by the case names returned by `bundle`. It compares the supplied lowercase SHA-256 before writing, checks stream capabilities and emptiness, writes the bytes, flushes and rereads each stream to check its SHA-256, and returns the record. The caller must securely create and retain distinct file handles beneath a trusted directory using no-follow/no-replace semantics, verify that different handles do not alias the same file, and persist the returned record safely. This API accepts handles only and does not establish those path or identity guarantees itself. An error after writing starts can leave partial files. No actual archive, CLI execution, or filesystem path verification is claimed by the in-memory tests.

The generator checks the archive header and manifest CRCs, manifest bounds, outer frame byte spans, and end marker. Its frame span checks are only a minimum of 8 bytes, maximum of 1 MiB plus 1024 bytes, and containment within the input; these are not the decoder's revision-specific extent checks. It does **not** decode frames, validate frame/file CRCs, paths, or establish that the input is a valid archive; use a previously verified input. Output mutations are the first frame length set to `0xffffffff`, last-byte truncation, header CRC bit flip, and archive revision 255 with recalculated header CRC.

CDF mutation is unsupported: packet grammar preservation and wire CRC resealing have not been proven. These fixtures exercise archive-envelope errors, not CDF validation. CLI rejection and recovery remain to be measured separately.
