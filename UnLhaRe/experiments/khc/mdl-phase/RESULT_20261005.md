# MDL工程計測とzero-row加算除去

2026-10-05、Windows x64/Rust1.98.1。前段hybridの7-Zipゲート未達を受けて、実測してから変更した。今回の変更は`src/khc/block/mod.rs`で検査済みzero rowへのingestを省く4行だけ。CDF/木選択/履歴順/形式/revision/decoder/APIは不変。bundleの検査は変更せず、初期ゼロHistと検査付き非ゼロ加算の不変条件を使う。独自圧縮原理ではなく冗長計算の除去。

固定toolchain/lockfile、未使用Attempt、source/tool/input pinsを使用。自環境で再ビルドしたhashが異なる場合は現EXE/sourceを別証拠として固定する。古いEXE/source/reportを上書きしない。追加unitなし、実public APIのframe比較と復元で検証する。
