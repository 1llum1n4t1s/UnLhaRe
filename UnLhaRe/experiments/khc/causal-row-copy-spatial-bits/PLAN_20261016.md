# 因果copy＋literal空間bitの固定screen

2026-10-16。製品統合を行わない独立実験。対象は新版UnLhaReのみ。

## 先に列挙する失敗

- countの過長ULEB・3byte超過・残量超過・無進捗、非最大copy、ゼロresidual、欠落literal、余分な終端。
- copy途中の幅変更見落とし、未来byte参照、encoder/decoderの票・bit表更新時点のずれ。
- 不正magic/version/予約欄/長さ/model順序・頻度・総量、raw/ wire CRC、切断、trailing byte、非正準range終端。
- 空・短い入力、全copy、全literal、幅変化、繰り返し、任意byte、最大1MiB境界での不一致・資源超過。
- valid→malformed→validの同一process呼出しが失敗後状態を引き継ぐこと、入力上限前の過大割当。
- literalに限定したモデル学習で予測が悪化すること、count/model/終端/CRCを含む実frameでサイズ改善が消えること。
- compiler/子processの一時物、保全ZIP・台帳も含め160MiB枠を超えること。資源不足を別root・枠拡大・旧証拠削除で回避しない。

## コード前に固定する方式

既存 `causal-record-vote/voter.rs` の整数pair投票をpath参照する。初期幅1、各byteを予測する直前のbest幅で復元済み `i-width`（未存在なら0）を読む。完成byteごとにcopy/literal両方で投票を更新する。

予測一致する最大連続数を正準ULEB（最大3byte）で符号化し、末尾でなければ非0 XOR residualを8bit、MSB順に符号化する。countは入力全体のcount-byte histogramだけから作る静的256-symbol CDF、総頻度32768。非0頻度を1ずつ確保し、残りを整数比例配分、剰余降順・symbol昇順で余りを配る。モデルはsupport u16 + 昇順(symbol u8,freq u16)。countとliteralは既存 `block/multi_range.rs` の同じrange streamに入れる。

literalのcontextはKRC1の4096-entry空間context式をそのまま使う。firstは直上行の左/中央/右3byte、secondは2行上の中央/右。行外は0、すべて既に復元済み。left初期値は直前plain byte下位4bit（行頭は0）。各residual bitで `left=((left<<1)|residual_bit)&15`、KRC1と同じcontext式と整数1/32更新、確率を1..32767へclampする。**bit表はliteralだけで更新し、copied byteでは更新しない**。初期値は全entry16384。残差とplain bitの混同を避ける。

wireは専用magic `KCS1BLK\0` / version1、40byte header。method0=stored、method1=coded。header: magic[0..8],version u16[8..10],method[10],reserved[11],raw_len u32[12..16],model_len u32[16..20],payload_len u32[20..24],raw_crc32[24..28],wire_crc32[28..32],reserved[32..40]。wire CRCは自身の4byteだけを除く全frame。codedはmodel+payloadがrawより小さいときだけ選択、それ以外は40byte+rawのstored。model/5byte range finish/2CRC/header/fallbackの全費用を計上する。decoderはraw<=1MiB、frame<=raw+40、model<=770、正準countとCDF（復号histogramから再構築一致）、range finishとCRCを検査する。

## 入力・資源・判定

唯一の外部入力は既存Tempの `01a0b076-4e26-7a71-ac35-32ed9259a871/canterbury-corpus-20261015/files/ptt5`。513216byte、SHA256 `0ec3a75089bb52342813496b17e51377bc9eba3cb519a444d67025354841d650`。新dataset・依存・float確率なし。旧KRC1とKRS1の計画/結果はliteralだけを空間bitで符号化する実frame結果ではない。

初回は登録入口 `run-storage-experiment.ps1 -MaxRunMiB 7`、timeout300秒。既存build/全Temp/TaskArtifactsを合算し、lifecycle固定160MiB、entry最低64を満たさなければ実行前に停止する。runtime論理作業領域64MiB以内に制限する。standalone rustcでexeとログを登録work内へ出す。Cargoを使う必要が生じたら `run-serial-cargo.ps1` のみ。清掃は保全ZIP/manifest照合後、Prunlet直接CMDの指定stageで行う。
