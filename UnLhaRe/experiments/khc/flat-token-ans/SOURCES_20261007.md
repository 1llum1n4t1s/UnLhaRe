# 出典 / 実装と先行技術の境界

確認日2026-10-07。[Fabian Giesenの rans_byte.h](https://github.com/rygorous/ryg_rans/blob/master/rans_byte.h) は2014/public domainとの告知、LOWER=2^23、byte renorm、逆順encode/前順decodeを明示する。今回のRustコードはCソースの移植ではなく同じ数学方式の再実装。public domainの方式を今回独自の圧縮原理とは呼ばない。

Q18のpacked event、固定grammar/履歴を保つjoint leaf CDFはこのprivate実装上の組合せ。最も近い技術であるtree probability積とrANSとの差分はPLANに限定し、世界初や7-Zip優位を未実測で主張しない。数学witness/partitionから実codec/native優位へ飛躍しない。量子状態圧縮を通常ファイル圧縮へ読み替えない。

所有権: token.rs/source-only worker-high、entropy.rs/source-only worker、codec.rs/harness/controller/文書は親。各担当編集停止後、親が引き取った。backendのsource担当14KiBは親codec予約から4KiBを再配分、全体96KiB/出力8MiB/RAM64MiBなどの上限は不変。元PLANの担当10KiBは初期配分として保持。compiler/runtimeは親のみ。
