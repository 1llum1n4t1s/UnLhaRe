# Leaf候補のMDL費用比較：失敗先行計画

根拠：build_nodeは整数量子化compact一択のleafとsplitを比較する。既存decoderはuniform/pure/compactすべてを受理するが、非ゼロcountsでuniform/pureが安い場合を探索していない。既存leafも必ず候補として残し、loss＋実metadata bitsが厳密に低いときだけuniform/pureへ変更する。pureは全minorが頻度2であるため、最大countのdominantが最小lossになる（tie先頭）。root uniform objectiveは0、非root uniformは3bit。splitとの比較は元leaf lossではなく選択したbest.lossで行う。

失敗候補：CDF total/support/tail破壊、k3uniform丸め差、uniform root費用0とlocal wire3bit混同、pure dominant誤選択、split比較が旧lossを参照、浮動小数の非有限、byte範囲/時間/RAM上限、範囲符号丸めによる理論改善と実サイズの不一致。既存valid_frequency/quantize/leaf_bits/parse-root CDF全比較を維持。decoderは変更せず、整数CDFを保存するので復号はfloat非依存。encoder出力変更は既存version内の戦略改善でありwire仕様変更ではない。

採否を先に固定：development alice29/kennedy総fullframeがbaseline比0.1%以上小さく、両入力ともサイズを悪化させない。両入力の圧縮/復号中央値が各baselineの110%以下、64MiB上限内。syntheticの範囲符号丸めによる最大1byte差は記録する。候補採用後、広い固定developmentを含む比較へ進み、未見セットは調整に使わない。これは小試作の採否で、GOAL_GATE_20261005の7-Zip完成条件を置換しない。
