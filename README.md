# UnLhaRe

このリポジトリでは、UNLHA32 の互換ライブラリを管理します。

- [UnLha32Re](UnLha32Re/README.md)：現在開発中の x86 完全互換版。安全性のための互換性例外と未検証範囲は、プロジェクトの README を参照してください。
- `UnLhaRe/`：将来の近代化版に使用する領域です。現時点では未実装です。

完全互換版のソース、ソリューション、ビルド・試験スクリプト、比較資料、生成物は `UnLha32Re/` 配下にあります。各手順は同フォルダーを作業ディレクトリとして実行してください。
